# Contributing

Keep this lab synthetic, local-only and provider-free. Do not submit credentials, private account data, signing keys, deployment code or Actions cleanup changes.

Explain the security boundary and add positive/negative tests before modifying policy/claims. Run full Python/native Rego/Terraform/browser/security/documentation gates. Preserve the95% all-module Python coverage requirement. Regenerate exact code maps and the tracked-file guide after source changes; do not hand-edit generated locations.

Use readable bounded contracts and privacy-safe fixed errors. Never replace native acceptance with mocks, hide failures, weaken signature/time/scope checks or claim cloud certification. Proposed real-provider integration requires a separate threat model/ADR and explicit account/deployment authority.
