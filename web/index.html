Help, scope and real-provider integration

Search filters evidence only; it does not change any permission. Allowed/Denied describes the observed access decision, while Pass/FAIL compares it with the expected test outcome. Tokens and signing keys are never displayed or downloaded.

The Python adapter actually verifies synthetic signed JWTs and calls native OPA. MFA evidence is an issuer assertion; this lab does not perform a second-factor challenge. The provider-free Terraform module generates AWS-shaped IAM documents and is tested with native plan-only tests. No AWS IAM Simulator or deployment was performed.

Before real integration, use an approved identity provider, validate its access-token profile and pinned issuer/JWKS lifecycle, enroll strong MFA, establish durable distributed revocation and clock discipline, review IAM policy interactions and require trusted HTTPS. Read the README, contracts, threat model and validation report. Do not enter private credentials here.
