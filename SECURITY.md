# Security disclosure

This is an owner-local synthetic educational lab, not production identity/access infrastructure. Do not deploy it publicly, enter real credentials or use its fixture issuer for real users.

Report a suspected flaw to Jason Stys through [GitHub](https://github.com/JasonStys) or [LinkedIn](https://www.linkedin.com/in/jason-stys-31b30b351/). Share minimal synthetic reproduction and affected source version; never send tokens, keys, private user data or unredacted real-provider logs.

Dependency/security results are best-effort dated evidence. No test/coverage/scanner can prove absence of vulnerabilities. See docs/security.md for trust boundaries and prerequisites before any real integration.
